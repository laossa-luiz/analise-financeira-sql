# 📊 Financial Analysis & Relational Modeling in SQL

This repository features a relational database solution built in **MySQL** for corporate financial data analysis. The project demonstrates database modeling, referential integrity using Foreign Keys (FK), and business analytical queries.

---

## 🛠️ Tech Stack & Concepts
- **Database Engine:** MySQL
- **SQL Concepts:** `JOINs`, Aggregate Functions (`SUM`, `AVG`, `COUNT`), Grouping (`GROUP BY`), Post-Aggregation Filtering (`HAVING`), and Ranking (`ORDER BY` + `LIMIT`).

---

## 📌 Key Queries in the Project

### 1. Consolidated Summary by Client and Category
Consolidates financial transactions above $300.00, calculating average ticket size and transaction volume.

### 2. TOP 3 Clients by Expense Volume Ranking
Filters exclusively for expenses and highlights the top 3 clients by total outflow volume.

---

## 🚀 How to Run the Script
1. Clone this repository or copy the code from `script_analítico.sql`.
2. Open your MySQL client (MySQL Workbench, DBeaver, or VS Code).
3. Execute the full script to build the schema, populate test data, and run the analytical reports.
